# Windows 11 Task Manager for Android 📱💻

Повноцінний віддалений **Диспетчер завдань Windows 11 на смартфоні Android** (та iOS) у вигляді Progressive Web App (PWA) з інтерфейсом у стилі Fluent Design (темна тема).

![Preview](web/icons/icon-192.png)

## Можливості

### 📋 Вкладка «Процеси» (Processes)
* **Список усіх активних процесів Windows** у реальному часі.
* Фільтрація за категоріями: **«Всі»**, **«Програми»**, **«Фонові»**, **«Windows»**.
* **Теплова колірна карта** навантаження (Fluent Heatmap: жовтий / помаранчевий / червоний кольори для високого споживання ЦП та ОЗП як у Windows 11).
* Сортування в один тап за стовпцями: **ЦП (%)**, **Пам'ять (МБ)**, **Диск (МБ/с)**, **Назва**.
* Швидкий живий пошук за назвою або PID.
* **Зняття завдань (Kill Task)**: безпечне завершення процесів прямо з телефону з захистом критичних системних компонентів ядра Windows.

### 📈 Вкладка «Продуктивність» (Performance)
* **Живі 60-секундні графіки (Canvas)** високої точності:
  * 🟦 **ЦП (CPU)**: загальне навантаження, тактова частота (ГГц), час роботи (Uptime), кількість процесів, потоків та дескрипторів.
  * **Режим «Логічні ядра»**: перемикання на сітку з 16 окремих графіків для кожного ядра процесора!
  * 🟪 **Пам'ять (RAM)**: обсяг використаної та доступної оперативної пам'яті (ГБ), відсоток навантаження.
  * 🟩 **Диск (Disk)**: швидкість читання та запису (МБ/с), статус усіх розділів (C:, D:, E: з шкалами вільного місця).
  * 🟧 **Мережа (Network)**: трафік відправлення / отримання (Кбіт/с, Мбіт/с), IPv4 адреса, ім'я комп'ютера.
  * 🟩 **Відеокарта (GPU)**: моніторинг NVIDIA GeForce / інтегрованої графіки (завантаження 3D %, пам'ять VRAM, температура °C, версія драйвера).

### ⚡ Керування та живлення
* Віддалене **блокування комп'ютера (Win + L)**.
* Переведення у **режим сну (Sleep)**.
* **Перезавантаження** та **Вимкнення** ПК з підтвердженням.
* Вибір частоти оновлення (0.5с / 1с / 2с / 5с) для збереження батареї смартфона.

### 📱 Встановлення на Android як нативний додаток (PWA)
1. Відкрийте адресу диспетчера в **Google Chrome** або **Brave** на телефоні.
2. Натисніть **(⋮)** у браузері та оберіть **«Додати на головний екран»** (або «Встановити додаток»).
3. Диспетчер з'явиться на робочому столі телефону і запускатиметься на весь екран без панелей браузера!

## 🚀 Запуск на ПК

### Варіант 1: Звичайний запуск (з виведенням QR-коду в термінал)
```powershell
python run.py
```
*У терміналі з'явиться текстовий QR-код. Просто наведіть камеру телефону для миттєвого відкриття!*

### Варіант 2: Запуск у системному треї (фоновий режим)
```powershell
python run_tray.py
```
*Диспетчер ховається у трей біля годинника Windows, не заважаючи на екрані.*
